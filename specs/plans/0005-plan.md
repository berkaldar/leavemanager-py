## Risks & open questions
- **A missed place.** A stored value put into markup without `esc()` leaves the hole open.
  Recommendation: step 4 lists every `%s` in `app.py` and says for each whether it holds stored
  text; review and QA probe the same way. A structural fix (Jinja templates for the pages) is
  bigger than this spec and is a later refactor.
- **`html.escape` instead of `markupsafe.escape`.** `markupsafe` is only a transitive dependency
  of Flask (not pinned by us). Recommendation: the standard library, so no new dependency
  and nothing to pin. It escapes `'` as `&#x27;` where Jinja writes `&#39;`; the tests judge by
  parsing, not by the entity's spelling.
- **The status badge is HTML built in the service** (architecture debt, `docs/architecture.md`).
  Recommendation: escape inside `status_badge` and leave moving it to the refactor spec.
- **Flipped tests are renamed** (`..._not_escaped` → `..._is_escaped`), which AC-7 lists among the
  allowed edits via R-5. Recommendation: accept; a name that says the opposite of what the test
  pins would mislead.
- **Sensitive area** — VERIFY breaks each criterion once; no one-pass review.
- **Models, your rule 3:** B-8 is on your list of fixes that need Opus in the main session.
  Recommendation: you run `/model` and switch to Opus before BUILD; review and QA run on Opus
  as always.
- Environment: doctor `0 fail, 0 warn` — profiles fast and full runnable; no new prerequisite or
  dependency.
